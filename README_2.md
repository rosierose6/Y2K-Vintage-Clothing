# Adding the Y2K Mesh Top guide to your journal

Two files here, both need to go to your GitHub repo (the one powering y2kvintageclothing.com):

- **`y2k-mesh-top-guide.html`** — the new post itself (new file)
- **`journal.html`** — your existing journal page, now with a new card at the top linking to the mesh top guide (this REPLACES your current journal.html)

## How to upload

1. Go to your repo on GitHub.
2. Click **Add file → Upload files**.
3. Drag in both `y2k-mesh-top-guide.html` and `journal.html`.
4. Scroll down, add a commit message like "Add mesh top guide", and click the green **Commit changes** button — don't skip this step, it's what actually saves the files.
5. Since `journal.html` already exists in your repo, GitHub will overwrite it with this new version (that's expected — it just adds the one new card, nothing else changed).
6. Give it a minute, then refresh https://www.y2kvintageclothing.com/journal.html — the new post should be the first card.
