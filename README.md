# Y2K Mesh Top Styling Guide

A single self-contained HTML page — no build step, no dependencies except Google Fonts (loaded via CDN link).

## How to upload this to GitHub

1. **Create a repo** on GitHub (e.g. `y2k-mesh-top-guide`) — click **New repository**, give it a name, and click **Create repository**.
2. **Add these files** — on the new repo's page click **uploading an existing file**, then drag in `index.html` and this `README.md`, and commit.
3. *(Optional)* **Turn on GitHub Pages** to get a live link:
   - Go to **Settings → Pages**
   - Under **Source**, choose the `main` branch and `/ (root)` folder
   - Save — GitHub will give you a URL like `https://yourusername.github.io/y2k-mesh-top-guide/` within a minute or two

That's it — because the page is named `index.html`, it'll load automatically at that URL.
